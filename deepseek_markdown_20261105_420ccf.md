# Politique de sécurité

Ce dépôt est une recherche conceptuelle. **Ne pas déployer en production**
sans audit Red Team indépendant (lot 5).

## Signaler une vulnérabilité

Ouvrir une issue privée ou contacter les mainteneurs. Ne pas divulguer
publiquement avant correctif.

## Périmètre

- Le code Python de PoC n'est pas un composant de sécurité.
- Le nœud FPGA n'est pas implémenté à ce jour.
- La source de dédoublement est la priorité d'audit (lot 4).
